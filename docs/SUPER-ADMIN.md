# Super Admin

El shell es un command center responsive con navegación completa para operación, automatización, contenido, finanzas, inteligencia y sistema.

El dashboard usa un caso de uso y repositorios. El adapter actual muestra tres tenants SAMPLE en onboarding y cero excepciones; no presenta métricas inventadas. Los módulos secundarios son rutas funcionales con estado vacío hasta sus hitos.

En móvil la barra lateral se convierte en drawer. No hay conexiones, mensajes, pagos ni publicaciones reales.
